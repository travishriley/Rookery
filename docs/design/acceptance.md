## Execution Strategy

Phase 0 validates draft JSON Schema with a real Draft 2020-12 validator, reference resolution and shape examples/negative probes, plus local link/prompt/diff checks. Schema acceptance is not policy acceptance. B01 adds pinned development dependencies, supported platform matrix and fixture CI; no application dependency is selected by a design check.

Boundary tests must use actual attempted forbidden access from isolated workers and independently observed fake targets. Mock method call counts alone are insufficient. Restore tests write to disposable temporary roots; no source or live root is writable. Isolated slicer smoke tests require the boundary first, an approved dependency/project inventory and no unreviewed hooks. Hardware tests remain human-run outside CI and are documented separately with no invented results.
